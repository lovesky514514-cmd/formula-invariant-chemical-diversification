# FICD v1.0.0 – Materials Letters reproducibility release

This is the first frozen public release of Formula-Invariant Chemical
Diversification (FICD).

## Frozen method

- Four scalarization families × four preference settings.
- Scoring-invariance index from rank fingerprints.
- Cross-family Top-K eligibility.
- Quality seed based on invariance and family support.
- Hard worst-rule-regret preservation.
- Diversity-improving one-for-one swaps only.

## Validation included

- Materials Project Li-Mn-O subset.
- WBM-derived oxygen-containing subset.
- ElMD distance validation.
- Leave-one-scoring-family-out validation.
- Materials Project crystal-system and space-group validation.
- Family-support sensitivity analysis with the v0.3 bookkeeping issue fixed.
